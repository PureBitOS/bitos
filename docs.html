1. Requirements

  • nasm — assembles kernel/*.asm to ELF64 objects
  • ld (GNU binutils) — links with kernel/linker.ld
  • grub-mkrescue (+ xorriso) — builds bootable bitos.iso
  • qemu-system-x86_64 — test boot (make run)
  • git — clone https://github.com/PureBitOS/bitos.git

2. Building & running

git clone https://github.com/PureBitOS/bitos.git
cd bitos
make          # nasm + ld + grub-mkrescue -> bitos.iso
make run      # qemu-system-x86_64 -cdrom bitos.iso -display none -serial stdio
make clean    # removes *.o, iso/boot/kernel.bin, bitos.iso

What Makefile does:

  1. nasm -f elf64 kernel/multiboot_header.asm -o kernel/multiboot_header.o
  2. nasm -f elf64 kernel/boot.asm -o kernel/boot.o
  3. ld -n -T kernel/linker.ld -o iso/boot/kernel.bin ...
  4. grub-mkrescue -o bitos.iso iso

Note: *.o, *.bin, *.iso are git-ignored (see .gitignore). Don't commit build artifacts.

4. Boot flow (v0.1)

  1. GRUB loads /boot/kernel.bin as Multiboot2 kernel.
  2. CPU jumps to start in 32-bit mode.
  3. VGA text buffer at 0xb8000 is filled with 0x0F20 (white-on-black spaces, 80×25).
  4. Message "BitOS v0.1 - Bare metal rising! (x64 foundation)" is written with attribute 0x0A (light green).
  5. cli then infinite hlt loop — system halts by design.

Next milestone per roadmap: long mode + better kernel foundation, then keyboard + basic shell.

6. Troubleshooting

  • grub-mkrescue missing — install grub-pc-bin + xorriso (Debian/Ubuntu) or equivalent.
  • QEMU opens no window — make run tries -display none -serial stdio first, then falls back to graphical QEMU.
  • Menu shows “AetherOS” — known leftover in iso/boot/grub/grub.cfg menuentry name; kernel payload is still BitOS. Rename it to BitOS when convenient.
  • Merge markers in README/LICENSE — if git status shows unmerged paths, resolve with git status → edit → git add → git commit before publishing.
