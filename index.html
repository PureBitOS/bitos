PureBitOS • minimal x64 operating system • v0.3

BitOS — now with keyboard + shell.

A minimal x64 OS written primarily in assembly. It boots via Multiboot2 + GRUB, enters 64-bit long mode, drives a real PS/2 keyboard over IRQ1, and drops you at a bitos> shell (help, ver, echo, clear, halt). Try the pre-release ISO below.

What it does today (v0.3)

  • Long-mode bootstrap with pre-flight checks (Multiboot magic, CPUID, LM-bit; red ERR:M/C/L on failure)
  • Own IDT + 8259 PIC remap + CPU fault handler; PS/2 keyboard on IRQ1 with US-layout scancode driver
  • bitos> shell: line editing, help, ver, echo, clear, halt — mirrored to serial for testing
  • Downloads: bitos-v0.3.iso pre-release — boots to the interactive shell

Source of truth: kernel/boot.asm, kernel/multiboot_header.asm, iso/boot/grub/grub.cfg.

Roadmap
