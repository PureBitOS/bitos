Package repository

BitOS has no package manager yet — but the hosting story is already real: bootable ISOs ship as GitHub Release assets on this account. The .bit package format below is the next milestone (roadmap step 3).

The kernel now runs a shell (roadmap steps 1–2 done). Package support is the next milestone.

  • Install story (planned): shell fetches .bit file → verifies manifest → extracts to RAM disk

Planned .bit format (draft)

{
  "name": "hello",
  "version": "0.1.0",
  "arch": "x64",
  "bitos": ">=0.2",
  "entry": "/bin/hello",
  "files": ["bin/hello", "share/hello.txt"],
  "sha256": "<hex>"
}
  • Single archive (e.g. hello-0.1.0-x64.bit = tar/zstd + manifest.json)
  • Manifest holds name, version, arch, min BitOS version, entry point, file list, hash
  • Registry index is a static packages.json served from GitHub Pages

For package authors (draft)

  1. Build a static binary for BitOS x64.
  2. Add manifest.json (schema above) + SHA-256.
  3. Pack as <name>-<version>-x64.bit.
  4. Open a PR against PureBitOS/bitos with the .bit link + manifest.
